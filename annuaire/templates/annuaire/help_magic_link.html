{% translate "Comment fonctionne la connexion par lien ?" %}

{% blocktranslate trimmed %} La connexion par lien (« magic link ») permet de se connecter sans avoir à saisir de mot de passe. {% endblocktranslate %}

  1. {% translate "Sur la page de connexion, cliquez sur « Recevez un lien de connexion par email »." %}
  2. {% translate "Saisissez l'adresse email associée à votre compte, puis validez." %}
  3. {% blocktranslate trimmed %} Si un compte existe avec cette adresse, vous recevez un email contenant un lien de connexion. Ce lien est à usage unique et valable 15 minutes. {% endblocktranslate %}
  4. {% translate "Cliquez sur le lien reçu par email : une page de confirmation s'affiche." %}
  5. {% translate "Cliquez sur le bouton « Confirmez votre connexion » pour terminer la connexion." %}

{% translate "Pourquoi une étape de confirmation ?" %}

{% blocktranslate trimmed %} Certaines messageries ouvrent automatiquement les liens reçus pour vérifier qu'ils sont sûrs. Sans cette étape supplémentaire, un tel lien pourrait être « utilisé » avant même que vous ne cliquiez dessus, et le lien ne fonctionnerait alors plus. Le bouton de confirmation garantit que c'est bien vous qui vous connectez. {% endblocktranslate %}

{% translate "Le lien a expiré ou ne fonctionne plus" %}

{% blocktranslate trimmed %} Passé le délai de 15 minutes, ou si le lien a déjà été utilisé, il n'est plus valide. Il suffit d'en redemander un nouveau depuis la page de connexion. {% endblocktranslate %}
