# Documentation

This documentation is published at https://reboulip.github.io/famille-busson/ on every
push to `main`.

- [`data_model.md`](data_model.md) — the data model: a diagram of the tables and a list
  of fields for each model. **Do not edit this file by hand.** It is generated from the
  code, and a pre-commit hook updates it when the models change. To update it by hand,
  run `uv run python manage.py generate_data_model_docs`.
- [`installation.md`](installation.md) — start here to set up a new installation: DNS,
  HTTPS, email, first start, backups.
- [`deployment.md`](deployment.md) — how the app is deployed to production: the Docker
  image, the server, the CI/CD workflows, and the environment variables.
- [`restore.md`](restore.md) — how to restore a backup, and how to test a restore.
- [`background_tasks.md`](background_tasks.md) — the background job queue and the
  scheduled jobs.
- [`observability.md`](observability.md) — logs, and error reporting with Sentry.
- [`design_system.md`](design_system.md) — the visual style (colours, fonts,
  components), and the rules to follow when you add a page.
- [`emails.md`](emails.md) — the emails the site sends, how they are built, and how to
  preview them.
- [`permissions.md`](permissions.md) — who can do what, page by page.
- [`authentication.md`](authentication.md) — how login by email link ("magic link")
  works. Written in French.
- [`search.md`](search.md) — the site-wide search.
- [`privacy.md`](privacy.md) — privacy features: personal data export, anonymisation,
  and the privacy notice.
- [`audit.md`](audit.md) — the audit log (staff only): what it records and how.
- [`corbeille.md`](corbeille.md) — the trash: deleted content can be restored for a
  while before it is removed for good.
- [`site_config.md`](site_config.md) — site settings that staff can edit: name, sender
  address, colours, logo, time zone, language.
- [`i18n.md`](i18n.md) — translation: how the site shows French or English, and how to
  add a language.
- [`ROADMAP_ARCHIVE.md`](ROADMAP_ARCHIVE.md) — roadmap items already shipped. They move
  here from `ROADMAP.md` at each release.
